# Security Policy

## Supported versions

Seules les versions sur la branche `main` sont supportées.

## Reporting a vulnerability

NE PAS ouvrir d'issue publique. Contactez le mainteneur via :

- GitHub : ouvrir une [private vulnerability report](https://github.com/foXaCe/hass-pronote/security/advisories/new)

Délai de réponse cible : 7 jours.
