# Configuration

Deux méthodes de connexion sont possibles lors de l'ajout de l'intégration.

## Option 1 : identifiants

Utilisez l'URL Pronote avec nom d'utilisateur, mot de passe et ENT (optionnel).

## Option 2 : QR code

1. Installez l'extension Chrome [QR Code Reader](https://chrome.google.com/webstore/detail/qr-code-reader/likadllkkidlligfcdhfnnbkjigdkmci)
2. Générez le QR code depuis votre compte Pronote
3. Scannez-le avec l'extension
4. Collez le JSON obtenu et saisissez le code PIN

## Compte parent

Si vous utilisez un compte parent, sélectionnez l'enfant à ajouter.

## Capteurs fournis

Les capteurs sont préfixés `pronote_LASTNAME_FIRSTNAME` : emploi du temps, notes,
devoirs, absences, évaluations, moyennes, punitions, retards, menus, moyennes
générales. Mise à jour toutes les 15 minutes.
