# FAQ

## L'intégration est-elle gratuite ?

Oui, cette intégration est open source (MIT).

## À quelle fréquence les données sont-elles mises à jour ?

Toutes les 15 minutes.

## Puis-je suivre plusieurs enfants ?

Oui, ajoutez plusieurs entrées de configuration (une par enfant).

## L'établissement n'apparaît pas dans les menus

Les menus ne sont disponibles que si l'établissement les active dans Pronote.
